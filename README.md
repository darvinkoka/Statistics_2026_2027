# Statistics_2026_2027

In this repository you can find out the laboratory sessions
of the course of statistics for Bioinformatics and Computational
Engineering and Risk Engineering

Prof. Alessandra Menafoglio
T.A. Darvin Koka 

OUTLINE:
____________________________________________________________________________________________
LAB0:

Exercise session with R. Introduction to the software R. Basics: R installation,
set working directory, use help(). Main objects: numeric, vectors, matrices, booleans.
Operators: sum, product, matrix product, columnwise/rowise sum and product. 
Conditionals: If/else. Dataframe implementatio; for cycle, personal functions and debugging 
using browser()
____________________________________________________________________________________________
LAB1:

Exercises on descriptive statistics: analysis and visualization of simple datasets. 
Differences between qualitative and quantitative variables, how to represent them. 
Qualitative: frequency tables, barplots and pie charts. Quantitative: summary statistics,
histograms, boxplots, assess (visually) the symmetry of the distribution.
Relation between a categorical and a quantitative variable: histogram/boxplot by factor. 
Relation between two quantitative variables: plot x-y, correlation.
